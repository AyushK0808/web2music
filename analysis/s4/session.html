Reading study — session setup

Experimenter only. The participant should not see this screen.

Session file

Welcome

You will read eight web pages, four times over, under four different audio settings. Each page is on screen for four minutes.

After each page there are four short questions about what you read, and a couple of questions about the audio. After each set of eight pages there is a short questionnaire about how the block felt.

One thing to remember: at any moment, if you find yourself wishing the audio would stop, press the space bar. You do not need to explain it and nothing will happen — we just want to know when it happened. Press it as often as you like.

The whole session takes about an hour. You can stop at any time.
